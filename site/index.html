Missing text is never blank on the website. The site falls back to English, so a gap shows as an English sentence. "The file says" is what the file claims about itself; the audit flags files that claim more than they deliver.

How to help, in four steps

  1. Pick a language you know. Press Edit in the table (you need a free GitHub account; GitHub makes you a copy to edit).
  2. Change only the text on the right of each colon. Never change a key, and keep every {{placeholder}} exactly as written.
  3. Update the _meta block at the top honestly: your name as translator, and whether it is human or machine translated.
  4. Send the change. A check runs automatically and tells you if a placeholder was damaged.

The full guide, with the rules and examples, is the translator guide. Prefer not to edit files? Use the Translation fix form.
